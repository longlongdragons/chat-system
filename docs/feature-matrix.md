# 功能对标矩阵：一个"完整"的实时聊天系统应该有什么

> 调研对象：[tinode/chat](https://github.com/tinode/chat)（13.5k★）、[Open-IM-Server](https://github.com/openimsdk/open-im-server)（14k★）、[Rocket.Chat](https://github.com/RocketChat/Rocket.Chat)（41k★）、[chatwoot](https://github.com/chatwoot/chatwoot)（21k★）、[vue-advanced-chat](https://github.com/antonreshetnyak/vue-advanced-chat)（1.6k★，前端组件级参考）。
> 用法：✅=本项目已实现，🚧=本轮补全，📅=路线图，❌=明确不做（说明原因）。

## 一、账号与资料

| 功能 | 本项目 | 备注 |
|---|---|---|
| 注册/登录（用户名/邮箱/手机） | ✅ | 三选一登录 |
| JWT 双令牌 + 全端吊销 | ✅ | RS256 + token_version |
| 个人资料编辑（昵称/签名/头像） | 🚧 | 后端 PATCH /users/me 已有，本轮补前端 |
| 用户搜索（昵称/用户名模糊搜） | 🚧 | **后端无接口，本轮新增** GET /users/search |
| 修改密码 / 邮箱验证 | 📅 P1 | 需邮件服务 |
| 好友申请体系 | ❌ | 当前定位是"团队内沟通"，会话即关系；好友体系适合陌生人社交场景，如转型再加 |

## 六、本轮补全清单（🚧 汇总）

**后端新增 2 个接口**：用户搜索、群成员列表。
**前端新增 8 项**：消息操作菜单（撤回/复制/引用）、引用回复气泡、图片/文件发送、emoji 网格、群管理抽屉（成员/拉人/踢人）、个人资料编辑、用户搜索开聊、桌面通知。

验收标准：`go build` + `go vet` + `vue-tsc` + `vite build` 全过；浏览器实测：搜用户开聊 → 发图 → 引用回复 → 撤回 → 群面板拉人踢人 → 改资料。
